# Climate Pulse Data Pipeline

This skill guides you in managing the full data ingestion and preprocessing pipeline for the Climate Pulse project.

## Prerequisites

- Virtual environment must be installed: `make install`
- OpenAQ API key must be set in `.env` as `DATA_OPENAQ_API_KEY`. Use the `credentials` skill if it is missing.

## Data Sources

| Source | Env Prefix | Key Config | Output |
|:---|:---|:---|:---|
| NOAA ERSST v5 | `DATA_` | `DATA_NOAA_ERSST_URL` | `datasets/raw/noaa_ersst.nc` → `datasets/processed/nino_features.parquet` |
| OpenAQ v3 PM2.5 | `DATA_` | `DATA_OPENAQ_API_KEY`, `DATA_OPENAQ_MAX_LOCATIONS` | `datasets/processed/openaq/` |
| NASA GISTEMP v4 | `DATA_` | `DATA_NASA_GISTEMP_URL` | `datasets/processed/gistemp.parquet` |
| Climate TRACE v7 | `DATA_` | `DATA_CLIMATE_TRACE_BASE_URL` | `datasets/processed/climate_trace.parquet` |
| ERA5 / WeatherBench2 (NWM only) | — | GCS public bucket (no auth) | `datasets/raw/nwm_era5/era5_5deg_6hr_2020_2022.nc` |

## Workflow

### 1. Download main climate datasets
```bash
make download-data
```
Fetches all four main sources (NOAA, OpenAQ, GISTEMP, Climate TRACE) via `src/scripts/download_data.py`.  
Pass `--source noaa|openaq|gistemp|climate_trace` to fetch a single source.  
Pass `--force` to bypass cache and re-download.

### 2. Download ERA5 data (NWM only — separate step)
The NWM requires ERA5 data which must be downloaded separately before NWM training:
```bash
PYTHONPATH=src .venv/bin/python src/scripts/download_nwm_data.py
```
This streams 2020–2022 data from the WeatherBench2 GCS Zarr store and saves to `datasets/raw/nwm_era5/era5_5deg_6hr_2020_2022.nc`.

### 3. Verify artifacts
After downloading, check that:
- `datasets/raw/` contains raw source files.
- `datasets/processed/` contains Parquet / NetCDF files.
- `datasets/metadata.json` is updated. **Do not edit this file manually.**

## Configuration

All data settings are controlled by environment variables with the `DATA_` prefix, loaded from `.env`, or overridden in `configs/default.yaml`.

Key variables:
| Variable | Default | Description |
|:---|:---|:---|
| `DATA_START_YEAR` | `1950` | Historical window start (≥ 1854) |
| `DATA_END_YEAR` | `2026` | Historical window end (≤ 2030) |
| `DATA_FOCUS_COUNTRIES` | `IND,USA` | Comma-separated ISO-2 codes for OpenAQ filtering |
| `DATA_OPENAQ_MAX_LOCATIONS` | `200` | Max sensor stations to sample |
| `DATA_OPENAQ_LIMIT` | `10000` | Max measurements to fetch per call |
| `DATA_OPENAQ_API_KEY` | *(required)* | Free key from explore.openaq.org |

## Idempotency

Re-running download scripts will update rather than duplicate records. Use `use_cache=True` (default) to skip sources that are already downloaded.

## Cleanup

```bash
make clean-downloaded-datasets   # Removes datasets/raw/, datasets/processed/, datasets/metadata.json
```
